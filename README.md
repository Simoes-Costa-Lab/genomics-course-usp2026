# 🧬 Genomics of Gene Regulation – Course Materials

This repository contains the teaching materials for the **Genomics of Gene Regulation course (QBQ5908)** at the **University of São Paulo (USP)**.

The course combines lectures on gene regulation with hands-on bioinformatics bootcamps focused on the analysis of genomic datasets.

The course website is available at:

🌐  https://simoes-costa-lab.github.io/genomics-course-usp2026/

---

## 📚 Course overview

The course is organized into thematic modules that introduce key genomic approaches used to study gene regulation:

- **Transcriptomics (RNA-seq)**
- **Chromatin accessibility (ATAC-seq)**
- **Protein–DNA interactions (CUT&RUN)**
- **Single-cell transcriptomics (scRNA-seq)**

---

## 🧭 How to use this material

The website is designed to serve both as:

- supporting material during the course
- a reference resource after the course

Participants can navigate modules directly from the course homepage.
