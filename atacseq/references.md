# Software Documentation

### MACS3

Peak calling software widely used for ATAC-seq and CUT&RUN.

* https://macs3-project.github.io/MACS/

### Bowtie2

Read alignment software.

* https://bowtie-bio.sourceforge.net/bowtie2

### deepTools

Visualization and quality-control toolkit.

* https://deeptools.readthedocs.io

### ChIPseeker

Peak annotation and visualization.

* https://bioconductor.org/packages/ChIPseeker

### HOMER

Motif discovery and peak annotation.

* http://homer.ucsd.edu/homer

### IGV

Genome browser for visualizing genomic data.

* https://igv.org

### Chromatin Accessibility and Gene Regulation

Comprehensive review of chromatin accessibility assays and interpretation.

* https://doi.org/10.1038/s41576-018-0089-8
