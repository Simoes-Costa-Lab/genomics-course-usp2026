# Transcriptomics (RNA-seq)

Esse módulo é uma introdução para análises de **sequenciamento de RNA (RNA-seq)**, um método para quantificar expressão gênica de amostras biológicas.

Vamos introduzir conceitos consceituais chaves e uma sessão prática de análises de RNA-seq.

---

# Objetivos

Após a conclusão desse módulo, os alunos devem ser capazes de:
- compreender princípios básicos de experimentos de RNA-seq
- reconhecer os principais passos para análise de RNA-seq
- realizar análises exploratórias de dados de transcriptoma

---

# Estrutura do Módulo

Esse módulo inclui:

- **Teoria:** princípios biológicos e computacionais de RNA-seq  
- **Sessões Práticas:** análise quiada de dados  
- **Exercícios:** sessão de desenvolvimento de projeto
- **Referência:** recursos adicionais e recomendação de leitura

---

# Tópicos

- Desing de Experimento de RNA-seq
- Controle de Qualidade de Dados de Sequenciamento
- Alinhamento de Reads
- Quantificação de Expressão Gênica
- Análises exploratórias e Expressão Diferencial
- Interpretação de Resultados
