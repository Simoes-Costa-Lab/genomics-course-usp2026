# Dataset Used in This Practical Session

### Neural Crest to Osteoblast Differentiation

The dataset used in this exercise is a published dataset from this publication: [BRD4 binds to active cranial neural crest enhancers to regulate RUNX2 activity during osteoblast differentiation](https://pubmed.ncbi.nlm.nih.gov/38063851/) by Musa et al. in Development (2024).  Mouse neural crest cells differentiated toward the osteoblast lineage across three developmental time points:

* D0 (Neural Crest Cells)
* D3 (Early Osteoblast Differentiation)
* D6 (Late Osteoblast Differentiation)

The practical exercises use a count matrix generated with featureCounts from aligned RNA-seq data.
