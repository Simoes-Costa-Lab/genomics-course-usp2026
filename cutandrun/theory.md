# Teoria

Esta seção apresenta os **conceitos biológicos e computacionais** necessários para entender os dados analisados neste módulo.

## Objetivos de aprendizagem

Ao final desta seção, os participantes deverão ser capazes de:

- compreender os princípios do método experimental
- reconhecer o tipo de informação gerada pelos dados
- entender as etapas gerais da análise computacional
